# 文档知识沉淀规则

## 这份规则解决什么问题

Flow Agent 的文档有不同读者和不同寿命。README 要让人快速上手，架构文档要保持系统边界清楚，功能文档要解释运行思想，规格文档要记录一次具体变更。把它们混写会让入口变长，也会让历史设计看起来像当前行为。

## 文档类型怎么选择

| 文档 | 回答的问题 | 面向读者 | 什么时候更新 |
| --- | --- | --- | --- |
| 根 `README.md` | 这是什么，如何启动，下一步读什么 | 所有人 | 项目定位、启动方式或主要入口变化 |
| `backend/README.md` | 后端如何组织、开发和验证 | 开发者 | 目录、依赖、配置、命令或测试入口变化 |
| `docs/ARCHITECTURE.md` | 模块如何协作，边界和生命周期是什么 | 开发者、维护者 | 总线、回合、生命周期、恢复或跨模块边界变化 |
| `docs/features/` | 某个能力为什么这样设计，如何运行 | 所有需要理解该能力的人 | 用户可感知行为、流程、状态或失败语义变化 |
| `docs/specs/` | 一次具体变更为什么做、怎么做、如何验证 | 实施者、评审者 | 需求、设计和实施过程开始时及完成时 |
| 变更记录 | 这次改了什么，验证了什么 | 协作者、维护者 | 重要变更完成后 |

一个简单判断方式：

```text
读者要启动项目？       -> 根 README
读者要改后端代码？     -> backend/README.md
读者要理解整体边界？   -> ARCHITECTURE.md
读者要理解一项能力？   -> features/<name>.md
读者要参与一次变更？   -> specs/<date>-<topic>/
读者要追踪本次交付？   -> 变更记录 / PR 描述
```

## 从需求到归档

```text
需求澄清
    |
    v
确认范围、读者和成功标准
    |
    v
规格 / 设计记录
    |
    v
实现与局部验证
    |
    v
更新 README、架构或功能文档
    |
    v
全量链接与测试检查
    |
    v
归档过程记录，保留当前说明
```

规格文档记录“这次为什么改”和“当时做了哪些选择”；功能文档记录“现在系统如何工作”。变更完成后，如果规格中的行为已经成为当前事实，应把读者需要的结论提炼到架构或功能文档，而不是要求读者阅读一整套历史任务记录。

## 哪些变更必须同步更新

- 改变项目启动命令、配置准备或主要入口：更新根 README；
- 改变后端目录、依赖方向、质量检查或运行命令：更新 `backend/README.md`；
- 改变 `ServiceApp` 生命周期、消息总线、会话隔离、提交顺序或恢复语义：更新架构文档；
- 改变被动回复、主动回复、后台任务、记忆、Agent Loop 或渠道的用户可感知流程：更新对应功能文档；
- 新增正式文档：同时更新根 README 和 `docs/README.md`；
- 只改变内部实现但不改变边界或读者理解：不为了“有改动”而复制源码细节到功能文档。

## 功能文档的写作要求

功能文档应优先回答以下问题：

1. 这项能力解决什么问题；
2. 谁或什么事件触发它；
3. 它经过哪些阶段和判断；
4. 哪些状态必须持久化或可恢复；
5. 成功、失败、取消和结果未知分别意味着什么；
6. 它与其他能力共享什么，又刻意隔离什么。

使用 ASCII 图表达主链路、状态机、并发关系或恢复过程。图中只放稳定的概念组件，不把临时函数名、源码文件名或平台私有细节当成架构边界。

## 文档自检清单

每次修改文档后检查：

- 标题是否直接表达文档用途；
- 是否删除与当前任务无关的背景和重复介绍；
- 结论是否以当前代码和配置为依据；
- ASCII 图和正文是否表达同一条流程；
- 相对链接是否指向存在的文件；
- 是否包含未完成占位标记、秘密、个人数据或运行时日志；
- 是否说明失败、恢复和边界，而不只描述成功路径；
- 是否同步更新了根 README、`docs/README.md` 或后端 README 的入口。

## 冲突时如何判断

出现冲突时，先以用户当前明确要求为准，再核对当前生效的 `docs/specs/README.md` 和代码行为；根 README 与 backend README 是入口说明，`docs/superpowers/` 是开发过程记录，历史规格不能覆盖当前实现。

如果代码、架构文档和功能文档出现不一致，不要用长篇解释掩盖差异：先确认代码行为，再在同一变更中更新对应文档，并在变更说明中写清楚影响范围。
