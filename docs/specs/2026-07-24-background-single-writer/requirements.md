# Requirements

## Goal

后台任务运行时应支持多个生产者（工具调用、事件和固定间隔），以受限并发执行任务，并由唯一持久化写入者更新 SQLite 状态。

## Functional requirements

- 插件任务可选声明 `interval_seconds` 或 `event_type` 触发器；不声明触发器的任务仍可由工具手动提交。
- 事件触发通过现有 `EventBus.subscribe()` 接收，固定间隔在运行时启动后计算，运行时停止后不再触发。
- 异步任务必须先进入有限容量 FIFO 队列，再由固定数量 worker 执行；不得为每次提交无限创建线程。
- 同一任务默认合并：任务已排队或执行时，重复提交不产生新的运行记录；任务可明确关闭合并。
- 可选防抖窗口仅在任务成功完成后开始计算；窗口内的新触发被忽略。
- 任务状态仍经过唯一 writer 顺序写入现有 SQLite 存储；已有手动执行、重试、重启中断标记和查询工具保持兼容。

## Non-goals

- 不引入异步任务处理器、LLM 注入或跨插件运行时快照租约。
- 不实现持久化调度声明、分布式 lease 或跨进程去重。
