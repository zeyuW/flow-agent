# Requirements

## Goal

插件热重载后，运行中的主动链路必须使用新一代数据源和主动模块；旧一代轮询任务不得残留。

## Functional requirements

- 插件贡献代际发布成功后，主动运行时刷新数据源、解析后的模块生命周期图和轮询任务。
- 刷新必须在主动事件循环中执行，并与单次 tick 互斥；不得在 watcher 线程直接修改异步对象。
- 新贡献编译或启动失败时保留旧主动运行快照，旧轮询任务继续运行。
- 新轮询任务准备成功后，旧轮询任务才停止并完成原子替换。
- 插件未启用或主动循环未运行时，刷新请求不得创建后台线程、任务或外部连接。
- 初始启动行为保持不变：主动循环首次 tick 仍立即执行。

## Non-goals

- 不实现跨进程插件快照租约。
- 不改变主动消息准入、霍克斯调度或数据源 ACK 语义。
