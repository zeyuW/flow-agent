# 被动回合停机取消：需求文档

- 状态：已验证
- 创建日期：2026-07-23

## 背景

主循环被取消时，已有的被动回合可能卡在模型或工具调用。旧行为会等待所有活跃回合自然结束，导致关闭过程无限等待。

## 目标

主循环停止或被取消时，必须取消尚未完成的被动回合，并等待其完成清理；关闭过程不得因挂起回合无限阻塞。

## 范围

- 包含：主循环的活跃回合取消与收束。
- 包含：覆盖挂起回合的回归测试。
- 不包含：模型调用超时策略、跨进程取消或后台任务取消语义。

## 约束

- 保持同一会话 FIFO 队列与既有 stop 行为。
- 清理过程不得泄露活跃任务引用。
- 新增说明性注释使用中文。

## 验收标准

- [x] 取消主循环会取消挂起的被动回合。
- [x] 挂起回合的清理逻辑得到执行。
- [x] 活跃任务集合在停止后为空。
- [x] 相关被动循环与可靠投递测试通过。
