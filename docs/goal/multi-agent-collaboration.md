# Goal：实现多 Agent 并行协作闭环

## 目标

实现类似 DeerFlow 的多 Agent 协作流程：用户提出复杂任务后，由主 Agent 负责拆解任务，通过 `delegate_task` 工具并行调用多个 SubAgent，收集执行结果后由主 Agent 汇总，并向用户返回一条最终回复。

本阶段优先保证单进程、本地环境下的功能闭环，不追求分布式和复杂工作流能力。

## 核心流程

```text
用户请求
  ↓
主 Agent 判断是否需要委派
  ↓
拆解为多个独立子任务
  ↓
通过 delegate_task 并行调用 SubAgent
  ↓
等待任务完成、失败或超时
  ↓
主 Agent 汇总结果
  ↓
向用户返回最终回复
```

简单问题不应强制创建 SubAgent。

## 功能要求

### 1. 主 Agent

主 Agent 需要能够：

- 判断当前任务是否适合委派；
- 将复杂任务拆分为多个独立子任务；
- 为每个子任务指定任务描述和 Agent profile；
- 通过工具调用 SubAgent；
- 等待并收集多个 SubAgent 的结果；
- 对结果进行归纳、去重和汇总；
- 向用户返回一条最终回复。

### 2. SubAgent

每个 SubAgent 需要：

- 拥有独立的任务上下文；
- 接收明确的任务描述；
- 复用现有 LLM、MCP、Skill 和 Tool 能力；
- 返回结构化结果；
- 支持成功、失败和超时三种结束状态；
- 不直接向用户发送最终消息。

建议结果结构：

```json
{
  "task_id": "task-1",
  "status": "completed",
  "result": "子任务结果",
  "error": null
}
```

### 3. 并行调度

调度器需要：

- 支持多个子任务并行执行；
- 单个子任务失败不能影响其他任务；
- 支持超时控制；
- 支持任务状态查询；
- 支持任务完成通知；
- 所有任务结束后返回统一结果集合。

并行调度逻辑集中在 `application/delegation`，不应散落到 passive 或 channel 层。

### 4. 主 Agent 汇总

主 Agent 汇总时需要：

- 区分成功、失败和超时结果；
- 合并多个 SubAgent 的有效内容；
- 去除重复信息；
- 不虚构失败任务的结果；
- 在最终回复中说明必要的失败或缺失信息。

### 5. Trace 追踪

一次用户请求使用一个统一的 `trace_id`，并关联整个执行树：

```text
trace_id
├── lead_agent
├── subagent.task-1
├── subagent.task-2
├── tool_call
└── final_synthesis
```

日志至少需要能够关联：

- 主 Agent；
- 每个 SubAgent；
- 工具调用；
- 执行状态；
- 开始时间和结束时间；
- 执行耗时；
- 错误信息。

前端应能够按 Trace 聚合查看一次请求的完整执行过程。

## 暂不实现

本次不实现以下能力：

- 工作流可视化编辑器；
- 分布式任务队列；
- 跨进程 SubAgent 集群；
- 复杂 Agent 角色市场；
- 自动长期规划；
- 多轮人工审批；
- 复杂的持久化恢复机制。

## 验收标准

至少满足以下场景：

1. 普通问题不创建 SubAgent；
2. 复杂问题可以拆分为两个子任务；
3. 两个子任务能够并行执行；
4. 两个子任务都成功时，主 Agent 能汇总结果；
5. 一个子任务失败时，另一个结果仍能参与汇总；
6. 子任务超时后，主 Agent 能继续完成最终回复；
7. SubAgent 不直接向用户发送消息；
8. 用户最终只收到一条汇总回复；
9. 同一次请求的日志拥有相同的 `trace_id`；
10. 日志能够区分主 Agent、SubAgent 和工具调用；
11. 不破坏现有普通对话、工具调用和定时任务功能。

## 执行要求

执行 Agent 需要：

1. 先读取本 Goal 和现有 delegation、agent、tool、passive、trace 相关代码；
2. 先输出简短实施方案和预计修改文件；
3. 先补测试，再实现功能；
4. 优先实现单进程下的并行调度闭环；
5. 复用现有 Agent、Tool、MessageBus、LLM 和日志基础设施；
6. 避免为了本目标进行无关重构和过度抽象；
7. 完成后运行相关测试和完整测试；
8. 最后汇报修改文件、实现内容、测试结果和遗留问题；
9. 不执行 `git commit` 和 `git push`。
